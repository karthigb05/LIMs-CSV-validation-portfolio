# LIMS Computer System Validation (CSV) Portfolio Project

A complete, GAMP 5-based CSV documentation package for a simulated Laboratory 
Information Management System (LIMS) implementation in a pharmaceutical QC / 
Analytical R&D lab. Built to demonstrate hands-on CSV documentation skills, 
anchored in real LIMS master data and analytical R&D experience.

**Regulatory framework:** GAMP 5 (Category 4 – Configured Product), 
21 CFR Part 11, EU GMP Annex 11

## Contents
- Validation Master Plan (VMP) summary
- User Requirement Specification (URS)
- Functional & Design Specification (FS/DS)
- Data Integrity Risk Assessment (ALCOA+ based)
- IQ / OQ / PQ / DQ protocols, including master-data-specific test cases
- URS–FS–Test Case traceability matrix
- Deviation & CAPA example
- Validation Summary Report

> Note: This is an illustrative portfolio document created to demonstrate 
> CSV documentation skills — not an actual regulated record from a real  company or system.
